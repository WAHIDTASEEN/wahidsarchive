The flow classification shown is the common reference for internal pipe flow and should be interpreted in context.

Formula

Re = ρVD / μ

  • ρ = fluid density
  • V = characteristic velocity
  • D = characteristic length/diameter
  • μ = dynamic viscosity

Common pipe-flow ranges

  • Re < 2300: laminar
  • 2300–4000: transitional
  • Re > 4000: turbulent
